# SecureBank Limitations

- This lab version provides administrator access only.
- Customer login and role-based access are planned for the final-term extension.
- Text files are suitable for local educational use but are not a substitute for a production database.
- The application currently uses a fixed administrator username and password.
- Concurrent multi-user access is not supported.
- Transaction rollback depends on local file-system operations.
- Interest, loans, cards, and audit-user management are outside the current scope.
